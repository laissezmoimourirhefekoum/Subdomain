# 🎯 Subdomain 

*Fait pour check tout les sous-domaines d'un site*
---

## Installation

### Prérequis

- **Python 3** ou plus
- Accès réseau (DNS)

### Installation 
```bash
git clone https://github.com/laissezmoimourirhefekoum/Subdomain.git
```
###


```bash
cd Subdomain
```
###
```bash
setup.bat 
```
###


**if doesn't work try:**
```bash
python main.py
```
